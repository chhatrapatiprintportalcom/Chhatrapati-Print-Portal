❓ Frequently Asked Questions

Quick answers about the portal

What is Chhatrapati Print Portal?

It is an all-in-one interface for printing, photo, PDF, design and digital-service resources.

How do I find a service?

Use the search box or click Services in the top menu. The Services button opens a menu instead of jumping down the page.

Can I use it on mobile?

Yes. The layout is responsive and includes a mobile menu.

Is Login real authentication?

The current Login/Join popup is a front-end demo. Real secure account authentication requires a backend authentication service.
