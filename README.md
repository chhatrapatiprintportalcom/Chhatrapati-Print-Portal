# Chhatrapati Print Portal

Starter Card Generator for the existing portal.

## Current flow
PDF Upload → PDF text extraction attempt → manual verification/edit → Preview → Print

## Next development phases
1. Better field extraction for each supported document format.
2. OCR for scanned/image PDFs.
3. Separate templates for Farmer ID, Maha Sarathi, Ration and other lawful reference/print formats.
4. A4 and 4×6 print layouts.
5. Save/load customer jobs locally.

> This starter intentionally treats government-ID related output as a reference/print workflow and does not reproduce security features or create counterfeit official credentials.
