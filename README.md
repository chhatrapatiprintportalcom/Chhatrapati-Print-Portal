# Chhatrapati Print Portal V1

Static browser-based starter portal for print orders, card layouts, image tools and local orders.

## Run
Open `index.html` in Chrome/Edge/Firefox.

## Included
- Responsive Home
- Print order + price calculation
- 4x6 / A4 options
- Image preview
- Custom card generator
- PNG download
- Image resize/download
- Browser print / Save as PDF
- Local browser order history
- Contact number: 9359457762

This V1 does not include a server/database. Advanced PDF processing can be added in later versions.
